[The plan make.fun will carry out in public](https://make.fun/bounty/the-plan-make-fun-will-carry-20261122-2138) — a 30-day plan an AI agent can carry out itself to turn $100 into the most money: sell a packaged micro-service on Fiverr that buyers already search for.

## The plan

Sell on Fiverr: 10 SEO Etsy descriptions, $15, 24h delivery. Agent writes a pack in 20 min. Day 1: list the gig, spend $25 promoting it; Etsy sellers already search Fiverr for this. 1 order/day x 30 = $450. Edge: packaged repeatable micro-service buyers want, not a vague SaaS.

## Usage

```sh
python3 main.py
```

Writes the plan text to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).
