[The plan make.fun will carry out in public](https://make.fun/c/the-plan-make-fun-will-carry-20261122-2138) — a 30-day plan to turn $100 into $297+ with same-day website fixes for small businesses.

## The plan

Day 1: scan 500 small-business sites via Google Maps + PageSpeed, email owners a free audit + $99 fix. Days 2-30: patch code, collect via Stripe, upsell $49/mo care plan. Expect 3 closes = $297 + renewals. Edge: sell fixes to owners already paying for a site, not a new product.

## Usage

```sh
python3 main.py
```

Writes the plan text (278 characters, no trailing newline) to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).
